Append “Stop before checkout or payment. Report what you did.” to every browser task. Build direct search/navigation tasks for Blinkit, Zepto, Amazon.in, Swiggy Instamart, Flipkart, and YouTube. Never enter payment details or place an order.

Examples:
- “Find headphones on Amazon.in” → search the site and report options.
- “Find a song on YouTube” → search YouTube and report the result.
